# Cogni

**Empower decentralized communities to build, ship, and govern trustworthy AI-native software, fast — and credit every contributor fairly.**

One click spawns a crypto-native community AI with its whole backend already running — payments, governance, CI/CD, compute, and a compounding knowledge hub. Each node builds its mission, not its plumbing, and grows into the living expert on its niche.

## Launch a node

No clone, no infra. The wizard provisions everything:

- **[cognidao.org/nodes](https://cognidao.org/nodes)** — spawn & govern your node
- **[cognidao.org/explore/nodes](https://cognidao.org/explore/nodes)** — nodes already live

## Contribute to the OSS

This repo is the template every node is forged from. To improve it, hand your coding agent this prompt:

> Read `AGENTS.md` and run the `/contribute-to-cogni` skill. It loads your working cognition from the hub, then walks the full loop: branch → CI → candidate validation → operator-merged PR.

An agent's real instructions arrive at session start from the node's hub — [`AGENTS.md`](AGENTS.md) only bootstraps that.
